## Теоретическая часть

### Изученные концепции (Часть 1 — React + Vite)

#### 1. **React и компонентный подход**
- **Функциональные компоненты** — основа современного React. Они принимают `props` и возвращают JSX. Использование небольших переиспользуемых компонентов улучшает архитектуру.
- **Хуки** — способ использовать состояние и другие возможности React. Основные: `useState`.

#### 2. **TypeScript**
- Статическая типизация, интерфейсы (`interface`) и типы (`type`).
- Повышение надёжности кода за счёт проверки типов на этапе разработки.

#### 3. **Управление состоянием**
- Хук `useState` для локального состояния.
- **Неизменяемость состояния** — ключевой принцип React. Состояние нельзя мутировать напрямую; нужно создавать новые копии объектов/массивов, чтобы гарантировать вызов рендера.

#### 4. **Методы массивов для работы с состоянием**
- `filter` — возвращает новый массив, исключая элементы (используется для удаления).
- `map` — возвращает новый массив, преобразуя элементы (используется для изменения статуса задачи).
- `...` (spread-оператор) — для копирования свойств объектов и создания новых массивов.

### Изученные концепции (Часть 2 — Next.js)

#### 5. **Next.js и App Router**
- Файловая маршрутизация: структура вложенных папок в `app/` определяет пути.
- `layout.tsx` — глобальный макет для всех страниц (добавлены шрифты и навигация).
- `page.tsx` — визуальное содержимое конкретного роута.

#### 6. **SSG (Static Site Generation) и маршрутизация**
- `generateStaticParams` — метод для предварительной генерации путей динамических маршрутов на этапе сборки.
- Динамические маршруты — папки с квадратными скобками, например `[slug]`. Параметр доступен в пропсе `params`.

```tsx
// App.tsx
const deleteTodo = (id: string) => {
  setTodos(todos.filter((todo) => todo.id !== id));
};

const toggleTodo = (id: string) => {
  setTodos(
    todos.map((todo) =>
      todo.id === id ? { ...todo, isDone: !todo.isDone } : todo
    )
  );
};
```

## Ответы на контрольные вопросы

### Часть 1 (React + Vite)

#### 1. Объясните принцип работы хука `useState`
`useState` — хук, который используется для хранения локального состояния в функциональном компоненте. Он принимает начальное значение и возвращает массив из двух элементов: самого значения состояния и функции для его обновления. Вызов функции обновления сообщает React, что нужно выполнить повторный рендер компонента с новыми данными.

#### 2. Почему в React важно использовать неизменяемое состояние?
React отслеживает изменения состояния, сравнивая старую и новую ссылки на объекты/массивы в памяти. Если мутировать массив напрямую (например, через `push()`), ссылка не изменится, и React "не поймет", что произошли изменения, следовательно — не перерисует интерфейс. Неизменяемость гарантирует предсказуемое поведение UI.

#### 3. Какой метод массива вы использовали для удаления задачи и почему?
Использовался метод `filter()`. Он идеально подходит, так как проверяет каждый элемент массива на соответствие условию (например, `todo.id !== id`) и возвращает абсолютно новый массив. Это позволяет соблюсти принцип неизменяемости.

#### 4. В чём преимущества TypeScript при разработке React-приложений?
TypeScript ловит ошибки на этапе написания кода, а не во время работы приложения. Он позволяет четко описать структуру пропсов (Props) компонентов, структуру состояния (например, интерфейс `TodoItem`), а также предоставляет мощное автодополнение в редакторах кода (VS Code).

### Часть 2 (Next.js)

#### 5. Что такое SSG (Static Site Generation) и как он реализован в вашем проекте?
SSG — это генерация HTML-страниц на этапе сборки приложения (`npm run build`). В Next.js 13+ страницы по умолчанию являются статическими (Server Components), если в них не используются динамические функции. В проекте SSG также применяется для блога через генерацию путей в `generateStaticParams`.

#### 6. Как работает файловая маршрутизация в Next.js?
В новом App Router каждый URL соответствует структуре папок внутри директории `app`. Если есть папка `about` и внутри нее `page.tsx`, то страница будет доступна по пути `/about`. Вложенные маршруты работают аналогично.

#### 7. Какие преимущества даёт использование `generateStaticParams`?
Этот метод позволяет заранее (до запроса пользователя) сгенерировать все страницы динамических маршрутов. В результате пользователь получает мгновенно загружающийся статический HTML. Это экономит ресурсы сервера и значительно улучшает SEO.

#### 8. В чём разница между `npm run dev` и `npm run build`?
`npm run dev` запускает локальный сервер для разработки. В этом режиме страницы собираются "на лету" при каждом запросе, работает мгновенная перезагрузка (HMR). `npm run build` производит оптимизированную финальную сборку проекта, минифицирует код и заранее рендерит статические страницы (SSG) для дальнейшего запуска через `npm run start` (или деплоя).
